## Design

### Data
`scripts/wordbank/<lang>` with `"characters": true`: the build adds to each entry
`syllables: [{ "text": "bù", "alsoTyped": [2], "otherTones": [] }]` — one per character of the headword, lower-case.
`alsoTyped`: other tones the same syllable takes through `pinyin.alternatives` (一, 不). `otherTones`: other tones of the same syllable among the character's readings (好 hǎo / hào). Tones are 0 (neutral) to 4.
The validator requires `syllables` that join to the headword's pinyin. The phone never splits pinyin into syllables itself. `WORDBANK_VERSION` is bumped.

### Pinyin logic (`src/lib/reading/pinyin.ts`, pure)
```ts
export interface Syllable { text: string; alsoTyped: number[]; otherTones: number[] }
export type PinyinResult = 'exact' | 'missing_tones' | 'wrong_tone' | 'wrong';
toneOf(s): 0..4            stripTone(s)           withTone(s, tone)   // mark on a/e, the o of ou, else the last vowel
isPinyinInput(s)           // Latin letters, tone marks, digits, spaces, apostrophes, hyphens, colon
gradePinyin(typed, syllables, sentenceForm?)
toneVariants(pronunciation, syllables, rng): string[] | null   // 2 or 3 wrong spellings
pinyinHint(syllables): { initial: string; count: number }
export const pinyinReading: ReadingSupport   // { grade, isInput, toneVariants, hint }
```
Grading: marks or numbers (`peng2you`, 5 or 0 = neutral), `v` or `u:` for ü, ü accepted for u after j q x y. Wrong letters → `wrong`. A written tone that is not the syllable's own, an `alsoTyped` one or the one in the sentence → `wrong_tone`. Right letters with a needed tone left out (none or only some) → `missing_tones`. Otherwise `exact`.
Variants change the tone of **one** toned syllable, never to a tone in `alsoTyped` or `otherTones`; fewer than 2 possible → `null`. Capitals and separators of the original are kept.

### Pack
`reading: ReadingSupport | null`; `italics: boolean` (false: target text and notes are set upright).

### When pinyin shows (`src/lib/reading/visibility.ts`, pure)
| Mode | Reading screens | Exercises before the answer |
|---|---|---|
| auto | shown | `new` tier shown; `learning`, `strong` hidden behind **Show pinyin** |
| always | shown | shown |
| tap | hidden behind **Show pinyin** (not in lists) | hidden behind **Show pinyin** |

- Tapping **Show pinyin** in an exercise caps the quality at `QUALITY.hintCap` (0.6) — in matching, only for the words whose pinyin was hidden.
- After the answer, pinyin shows at no cost.
- Never for the target where it gives the answer away: the blank of a cloze; the word of tone choice.
- Flip card: before the reveal only in `always`; after it, always.
- Setting stored in MMKV `reading-settings` (device preference, not in backups); the section shows only for a pack with `reading`.

### Formats
- **Typed cloze:** input of Latin letters → pinyin grading: `exact` 1.0, `missing_tones` 0.7, `wrong_tone` 0 with its own message, `wrong` 0. Other input → characters, as today. Hint: first initial and syllable count.
- **Tone choice** (`tone_choice`, tiers `new`, weight 1, quality 0.8 / 0): the word in characters with a speaker button; 3–4 pinyin options; after the answer the meaning. Last in `DEFAULT_REGISTRY` before the flip card, so picks for other languages do not change.
- **Practice menu:** `practiceFormats()` = the six, plus `tone_choice` for a pack with `reading`, minus `find_mistake` for a pack without gender, cases and choices.

### Strings
Pack overlay only (it, en), required by `targetStrings` for a pack with `reading`.
